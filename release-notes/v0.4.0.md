# oh-my-deepseek v0.4.0

## 客户端原生插件市场

控制台新增「插件市场」页。这个页面由客户端自己实现，**不加载、嵌入或依赖 `dshmarket` 的前端**；社区目录只作为经过校验的数据源。

- 搜索插件、作者和中英文描述
- 按安装状态、可更新状态与分类筛选
- 按收藏数、下载数、收录时间和名称排序
- 在界面内安装、更新和卸载当前 web profile 的插件
- 对照 profile 的实际依赖显示已安装版本和可更新状态
- 插件变更时暂停 Harness，完成后恢复原来的运行状态
- 自动把带有 `dsh.bundle.patch` 的插件加入或移出 bundle 栈

包管理完全走客户端自带的 Node.js 与 Corepack，并固定使用 pnpm 11.20.0；macOS 和 Windows 用户都不需要再从控制台执行一段平台相关的安装命令，也不需要预装 pnpm。

## 打包修复

- macOS 产物会在没有 Developer ID 时执行完整的 ad-hoc 深度签名并验证应用包，避免 Electron 内部文件签名不一致造成的损坏判断。它仍然**没有 Apple 公证**；首次打开仍需右键「打开」或在「隐私与安全性」中放行。
- Windows 产物现在显式包含 Node 运行时根目录下的 `node_modules`，并在打包阶段检查 npm 与 Corepack 的入口文件，避免开发机可用、安装包内缺少包管理器。
- 烟测新增插件完整生命周期：加载目录、安装、加入 bundle、重启 Harness、卸载、再次重启，并检查退出后无残留进程。
