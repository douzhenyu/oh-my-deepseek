# oh-my-deepseek v0.4.1

## 关闭窗口后在后台继续运行

关闭 Harness 或客户端控制台窗口时，不再直接退出应用，也不会中断正在进行的任务。窗口会被隐藏，Harness 后台继续运行；只有从应用菜单或托盘菜单明确选择「退出」，才会停止后台并回收进程树。

- macOS：点击 Dock 图标可以重新打开 Harness；应用菜单仍可打开控制台或退出
- Windows：新增通知区域托盘图标，单击可重新打开 Harness
- Windows：右键托盘图标可打开 Harness、打开控制台、重启后台、停止后台或退出
- Windows：第一次关闭全部窗口时会提示客户端仍在后台运行
- 再次启动客户端时，单实例入口会恢复现有窗口，不会启动第二个后台

## 验证

- 自动化烟测会触发真实 BrowserWindow 关闭事件，检查窗口没有被销毁、后台 PID 没有变化，并重新加载同一 Harness 页面
- 打包阶段会检查 Windows 产物内存在托盘图标资源
- 明确退出后仍会验证 supervisor 与 Harness 进程全部结束

> Windows x64 产物仍是在 macOS 上交叉打包；资源完整性会自动检查，但托盘交互需要在 Windows 真机最终确认。
