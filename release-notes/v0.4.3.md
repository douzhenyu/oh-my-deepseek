# oh-my-deepseek v0.4.3

## 修复 Harness 更新，并允许移除旧版本

本版本修复从 Finder 启动客户端后更新 Harness 报 `npm exited with code 127` 的问题，并允许用户在切换到新版后移除旧的内置版本。

- npm 安装环境会优先找到客户端自带的 Node.js，原生依赖安装脚本不再报 `node: command not found`
- 已切换到新版时，旧的内置 Harness 会显示“删除”按钮
- 删除内置版本会将它从可选版本与自动回退中移除，并在重启后保持；App 内的只读兜底副本不会被物理删除，以免破坏签名
- 用户安装的 Harness 版本仍会直接删除对应文件

## 验证

- 模拟 Finder 精简 PATH 的 macOS arm64 打包产物更新至 dsh 0.1.6-alpha.1
- 更新后启动新版并移除内置旧版
- 重启后继续使用新版，旧版不再进入可选列表
- TypeScript 类型检查、构建与基础启动烟测
- macOS arm64 与 Windows x64 打包资源检查

> Windows x64 产物在 macOS 上交叉打包；资源结构会自动检查，最终交互仍建议在 Windows 真机确认。
